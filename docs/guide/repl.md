# REPL 사용법

`chaude`를 인자 없이 실행하면 대화형 화면(REPL)이 열립니다. 이 문서는 화면에서 쓰는 기능을 모두 설명합니다. 명령줄 옵션은 [cli.md](cli.md)를 보세요.

## 시작하기

프로젝트 폴더로 이동해서 실행합니다.

```sh
cd ~/my-project
chaude
```

화면 위쪽에 환영 상자가 보이고, 모델, 작업 폴더, 회전 임계값이 여기 표시됩니다. 아래 입력창에 질문이나 작업을 적고 Enter를 누르면 됩니다.

- 기본 모델은 Opus입니다. 메인 모델은 `/settings`에서 바꿀 수 있습니다.
- 시작할 때 권한 모드는 `auto`입니다. 모드는 `shift+tab`이나 `/mode`로 바꿉니다. 자세한 내용은 아래 "권한 모드"에 있습니다.
- 터미널이 아니거나 `HARNESS_PLAIN` 환경변수가 설정되어 있으면 전체 화면 대신 일반 텍스트 REPL로 동작합니다. 자세한 내용은 아래 "일반 텍스트 모드"에 있습니다.

## 입력하고 답 받기

| 키 | 동작 |
|---|---|
| Enter | 입력을 보냅니다 |
| `alt+enter` 또는 `ctrl+j` | 줄을 바꿉니다 |
| 줄 끝에 `\` 후 Enter | 줄을 바꿉니다 |
| `↑` / `↓` | 이전 입력을 불러옵니다 |
| `tab` | 명령을 완성합니다 |

- 입력 기록은 `<프로젝트>/.chaude/history.jsonl`에 저장되고 최대 500개까지 남습니다. 다시 실행해도 남습니다.
- `/`로 시작하면 명령 목록이 열립니다. 목록이 열려 있으면 `↑` / `↓`로 고르고 `tab`으로 완성합니다.

## 상태 줄과 사용량

화면 맨 아래 상태 줄의 왼쪽에는 다음 항목이 순서대로 보입니다.

- 컨텍스트 바: 현재 컨텍스트 토큰이 회전 기준에 얼마나 가까운지 보여 줍니다.
- 사용량 비율: 5시간 한도의 사용률(%)과 리셋 시각입니다. 아래 "5시간 사용량의 출처"에 자세히 나옵니다.
- `rot N`: 세션을 넘긴 횟수입니다.
- `mode <이름>`: 권한 모드가 `default`가 아닐 때만 보입니다.
- `agents N running (bg N)`: 실행 중인 에이전트 수와 그중 백그라운드 수입니다.
- `복사됨 (N자)`: 드래그로 고른 글자를 복사했을 때 2초 동안 보입니다.

오른쪽에는 자주 쓰는 키 안내가 있습니다. 권한 확인 창이 떠 있으면 `y allow · n deny`가 대신 보입니다.

답변이 끝날 때마다 사용량 줄이 하나 붙습니다.

```
[ctx 12,345 | in N cr N cc N out N | $0.0123 | 5h N | sess abcdef12 rot 0]
```

- `ctx`: 현재 컨텍스트 토큰 수입니다. 회전 기준으로 쓰입니다.
- `in`, `cr`, `cc`, `out`: 입력, 캐시 읽기, 캐시 쓰기, 출력 토큰 수입니다.
- `$`: 이 턴의 비용(USD)입니다.
- `5h`: 5시간 사용률입니다. 아직 값을 받지 못했으면 `?`입니다.
- `sess`: 현재 세션 ID 앞부분입니다.
- `rot`: 세션 회전 횟수입니다.

### 5시간 사용량의 출처

- 상태 줄과 사용량 줄의 `5h` 값은 자식 `claude` 프로세스가 스트림으로 보내는 `rate_limit_info`의 5시간 창(`five_hour`) 사용률에서 옵니다. 별도 호출을 하지 않습니다.
- 값은 `claude`가 알려 줄 때까지 `?`로 보입니다.

### /usage

- `/usage`는 플랜 사용량과 한도를 전체 화면으로 보여 줍니다.
- 이 화면은 `claude -p /usage`를 따로 한 번 호출해서 만듭니다. 진행 중인 답변에는 영향을 주지 않습니다.
- 답변 중에도 `/usage`를 쓸 수 있습니다.
- 화면을 닫으려면 `esc`, `q`, Enter, `ctrl+c` 중 하나를 누릅니다. 스크롤은 `↑` / `↓`(또는 `k` / `j`), `pgup` / `pgdown`, `home` / `end`로 합니다.
- 백그라운드에서 5분(`usagePollEvery`)마다 `claude -p /usage`를 한 번 호출합니다. 결과의 `Current session` 사용률과 `Current week` 사용률을 메트릭 기록(`stage=usage`, `session_pct`, `week_pct`)에만 남깁니다. 화면의 값은 바뀌지 않습니다. `HARNESS_USAGE_POLL=0`을 설정하면 이 자동 조회를 끕니다.

## 권한 모드

권한 모드는 도구를 어떻게 쓸지 정합니다. 네 가지가 있습니다.

| 모드 | 동작 |
|---|---|
| `default` | 권한 확인 창을 띄웁니다 |
| `acceptEdits` | 파일 편집 도구(Edit, Write, MultiEdit, NotebookEdit)는 묻지 않고 허용합니다. 나머지는 묻습니다 |
| `plan` | 읽기 도구만 허용합니다. 수정하거나 명령을 실행하는 요청은 거부됩니다 |
| `auto` | chaude 쪽 권한 확인 창을 띄우지 않고 모든 요청을 허용합니다. 자식 `claude`는 `--permission-mode auto`(Claude Code의 auto 모드)로 뜨며 `bypassPermissions`가 아닙니다 |

- 시작할 때 모드는 `auto`입니다.
- `shift+tab`을 누를 때마다 `default` → `acceptEdits` → `plan` → `auto` → `default` 순서로 바뀝니다. 모드가 바뀌면 `mode: <이름>` 안내가 한 줄 나옵니다.
- `/mode`만 입력하면 현재 모드를 보여 줍니다. `/mode <이름>`으로 바로 바꿉니다. 이름은 `default`, `acceptEdits`, `plan`, `auto` 중 하나입니다.
- 권한 확인 창이 뜨면 `y`나 Enter로 허용하고, `n`이나 `esc`로 거부합니다. `ctrl+c`는 거부하고 답변을 멈춥니다.

## 답변 멈추기와 되돌리기

- 답변 중 `esc`: 답변을 멈춥니다.
- 답변 중 `ctrl+c`: 답변을 멈춥니다.
- 대기 중 `ctrl+c` 또는 `ctrl+d`: 종료합니다. `/exit`, `/quit`도 종료합니다.
- 입력창이 비어 있을 때 `esc`를 600ms 안에 두 번 누르면 되돌리기 창이 열립니다. `↑` / `↓`로 이전 질문을 고르고 Enter를 누르면, 그 질문 시점으로 화면과 입력창이 돌아갑니다.
- 되돌리기는 화면과 입력창만 바꿉니다. 자식 세션의 컨텍스트는 그대로 남습니다. 컨텍스트까지 비우려면 `/clear`를 쓰세요.

## 스크롤과 복사

- 마우스 휠로 스크롤합니다. 기본값은 켜짐입니다.
- `pgup` / `pgdn`, `ctrl+b` / `ctrl+f`로 한 화면씩 스크롤합니다.
- `shift+↑` / `shift+↓`로 한 줄씩 스크롤합니다.
- 입력창이 비어 있으면 `home` / `end`로 맨 위와 맨 아래로 갑니다.
- `/mouse`는 휠 스크롤을 끄고 켭니다. 끄면 터미널에서 드래그로 글자를 고를 수 있습니다. 대부분의 터미널은 `shift`를 누른 채 드래그해야 고를 수 있습니다.
- 드래그로 고른 글자는 마우스를 놓는 순간 자동으로 복사됩니다. 상태 줄에 `복사됨 (N자)`가 2초 보입니다.

## 슬래시 명령

슬래시 명령은 `/`로 시작합니다. 답변 중에는 아래 여덟 개만 바로 쓸 수 있습니다. 나머지는 답변이 끝난 뒤에 입력합니다.

답변 중에 쓸 수 있는 명령: `/usage`, `/version`, `/help`, `/status`, `/mode`, `/mouse`, `/view`, `/settings`

답변 중에 다른 명령을 치면 "답변이 끝난 뒤 다시 입력" 안내가 뜹니다.

| 명령 | 하는 일 |
|---|---|
| `/help` | 명령 목록과 키 안내를 보여 줍니다 |
| `/status` | 모델, 컨텍스트 토큰, 세션을 보여 줍니다 |
| `/model [이름]` | 이름이 없으면 현재 모델을 보여 줍니다. 이름을 주면 그 모델로 바꿉니다 |
| `/settings` | 설정 화면을 엽니다. 아래 "설정 바꾸기"에 나옵니다 |
| `/resume [n\|슬러그]` | 기록 주제 목록을 보거나 하나를 엽니다. 아래 "/resume"에 나옵니다 |
| `/resume claude [검색어]` | Claude Code 세션을 검색어로 찾습니다 |
| `/import [id\|latest]` | Claude Code 세션을 가져와 현재 세션을 대신합니다 |
| `/view [id 앞부분]` | Claude Code 세션을 찾아봅니다. 아래 "에이전트와 세션 보기"에 나옵니다 |
| `/clear` | 새 세션을 시작합니다. 핸드오프 노트는 이어받습니다 |
| `/rotate` | 새 세션으로 넘깁니다(핸드오프) |
| `/mode [이름]` | 권한 모드를 보거나 바꿉니다 |
| `/mouse` | 마우스 휠 스크롤을 켜거나 끕니다 |
| `/usage` | 플랜 사용량과 한도를 전체 화면으로 보여 줍니다 |
| `/version` | chaude와 Claude Code 버전을 보여 줍니다 |
| `/update` | GitHub 최신 릴리스를 확인해 더 새 버전이면 이 바이너리를 교체합니다. 재시작해야 적용됩니다. (EN: check the latest release and replace this binary if newer; restart chaude to use it. On unix, if the binary dir is not writable it prints `update failed: <dir> is not writable; nothing changed. reinstall chaude to ~/.local/bin (no sudo): curl -fsSL https://raw.githubusercontent.com/int-ttt/chaude/master/install.sh | bash` and changes nothing.) |
| `/cost` | 사용량과 비용을 `claude`에 물어 보여 줍니다 |
| `/context` | 카테고리별 컨텍스트 사용량을 `claude`에 물어 보여 줍니다 |
| `/compact` | `claude`의 컨텍스트를 압축합니다 |
| `/config` | `claude`의 설정을 보거나 바꿉니다. 형식은 `/config 키=값`입니다 |
| `/mcp` | MCP 서버 상태를 `claude`에 물어 보여 줍니다 |
| `/agents` | `claude`의 서브에이전트 정보를 보여 줍니다 |
| `/init` | 저장소를 분석해 CLAUDE.md를 제안합니다. 턴을 하나 실행합니다 |
| `/review` | 현재 변경 사항을 검토합니다. 턴을 하나 실행합니다 |
| `/doctor` | 설치와 설정을 점검합니다. 턴을 하나 실행합니다 |
| `/exit`, `/quit` | 종료합니다 |

- `/memory`와 `/permissions`는 `claude` 쪽에서 대화형으로만 쓸 수 있어서 chaude에서는 안내 메시지만 나옵니다.
- 위에 없는 명령을 치면 `unknown command ... (try /help)` 안내가 나옵니다.

### /resume

`/resume`은 두 가지 기록을 다룹니다. 동작이 다르므로 구분해서 보세요.

1. chaude 기록 (`/resume`, `/resume <n|슬러그>`)
   - 검색어 없이 입력하면 이 컴퓨터의 chaude 프로젝트 기록 목록이 열립니다.
   - 단, 직전 chaude 실행이 `/exit` 없이 끝났다면(창 강제 종료, `kill -9` 등) 목록 대신 그 세션을 `/resume claude`처럼 가져옵니다. 현재 세션이 그 세션으로 바뀌고, `notes/tmp/long/<세션>.md` 요약 파일이 만들어지며, 새 세션의 첫 입력이 이 파일을 먼저 읽도록 합니다.
   - 목록에서 `↑` / `↓`로 고르고 Enter를 누르면 그 기록의 내용을 화면에 불러옵니다. 보기만 하고 현재 세션은 바뀌지 않습니다.
   - `esc`, `ctrl+c`, `q`로 닫습니다.
2. Claude Code 세션 (`/resume claude [검색어]`)
   - 검색어에 맞는 세션이 하나면 바로 가져옵니다. 현재 세션을 대신합니다(`/import`와 같습니다).
   - 여러 개면 선택창이 열립니다. 최대 30개까지 보여 줍니다.
   - 선택창에서 Enter를 누르면 고른 세션을 `/import`로 가져옵니다. 현재 세션이 그 세션으로 바뀝니다.
   - 숫자 키 `1`~`9`로도 고를 수 있습니다. `esc`, `ctrl+c`, `q`로 취소합니다.
   - 강제 종료 뒤 검색어 없이 `/resume`을 치면 위 1번 대신 이 방식으로 그 세션을 가져옵니다.

## 에이전트와 세션 보기

- `ctrl+t`: 이 세션의 에이전트 목록을 엽니다. 에이전트가 없으면 `no agents yet`이 나옵니다.
  - `tab` / `→`와 `shift+tab` / `←`로 에이전트를 바꿔 봅니다.
  - `↑` / `↓`(또는 `k` / `j`), `pgup` / `pgdown`, `home` / `end`로 로그를 스크롤합니다.
  - `esc`, `q`, `ctrl+c`로 닫습니다.
- 백그라운드 에이전트의 결과는 `notes/runs/<YYMMDD>-agent-<id>.md`에 저장됩니다.
- `/view`: 이 chaude 프로젝트에서 만든 Claude Code 세션 목록을 보여 줍니다.
  - `↑` / `↓`로 고르고 Enter를 누르면 그 세션의 프롬프트 목록이 열립니다.
  - 프롬프트 목록에서는 `←` / `→`(또는 `k` / `j`)로 프롬프트를 넘기고, `home` / `end`로 처음과 끝으로 갑니다.
  - `esc`를 누르면 목록으로 돌아갑니다. `q`나 `ctrl+c`는 화면을 닫습니다.
  - `/view <id 앞부분>`을 쓰면 목록을 건너뛰고 바로 엽니다.
- `/view`는 답변 중에도 쓸 수 있습니다.

## 설정 바꾸기

`/settings`에서 다음 값을 바꿉니다.

| 항목 | 값 | 기본값 |
|---|---|---|
| 기록 보존 기간 | 일 수. 0이면 계속 보관합니다 | 30일 |
| 추가 코더 수 | 0~8 | 4 |
| 메인 모델 | `opus`, `sonnet`, `fable` 중 하나 | `opus` |

- `↑` / `↓`로 항목을 고르고, `←` / `→` 또는 Enter로 값을 바꿉니다.
- `esc`, `ctrl+c`, `q`를 누르면 저장하고 닫습니다.
- 값은 `<프로젝트>/.chaude/settings.json`에 저장됩니다. 프로젝트마다 따로 저장됩니다.
- 보존 기간, 추가 코더 수, 메인 모델은 다음 세션을 시작할 때 적용됩니다.
- 추가 코더(`coder2`부터)는 3570초 동안 쓰지 않으면 자동으로 종료됩니다.

## 상주 세션

chaude는 답변을 처리하기 위해 여러 `claude` 세션을 함께 띄웁니다.

- `main`: 메인 세션입니다. `/settings`의 메인 모델로 돌아갑니다.
- `prompter`: 입력을 짧게 정리해서 메인에 전달합니다. haiku 모델입니다.
- `tui`: 답변을 존댓말로 다듬어 화면에 보여 줍니다. haiku 모델입니다.
- `coder`: haiku 코더입니다. 간단한 수정과 조회를 맡습니다.
- 추가 코더 `coder2`부터는 `/settings`의 추가 코더 수만큼 필요할 때 띄웁니다.

상주 세션은 처리 중일 때만 실행 목록에 보입니다. 메인 모델은 조회와 반복 작업을 `haiku-*` 에이전트에 맡깁니다. 에이전트 정의는 [models-and-agents.md](models-and-agents.md)에 있습니다.

## 회전과 핸드오프

- 답변이 끝났을 때 컨텍스트 토큰이 임계값 이상이면 자동으로 새 세션으로 넘어갑니다. 이를 회전이라고 합니다.
- 회전할 때 이전 대화의 핸드오프 노트를 새 세션에 넘깁니다. 대화는 이어집니다.
- 임계값은 메인 모델이 Opus면 200,000 토큰으로 고정됩니다. 다른 모델은 기본 80,000 토큰이며 시작 옵션 `--threshold`로 바꿉니다.
- 백그라운드 에이전트가 돌고 있으면 회전을 미룹니다. 최대 10분까지 기다린 뒤 회전합니다.
- `/rotate`로 언제든지 직접 넘길 수 있습니다.
- 회전할 때 한 줄 표시를 보려면 `--show-rotation`을 쓰세요.

## 일반 텍스트 모드

전체 화면 대신 일반 텍스트로 동작하는 모드입니다. 다음 중 하나이면 이 모드로 실행됩니다.

- 표준 입력이 터미널이 아닐 때(예: 파이프로 실행할 때)
- `HARNESS_PLAIN` 환경변수가 설정되어 있을 때

이 모드에서는 상태 줄과 키 조작이 없습니다. 입력을 한 줄씩 받고 답을 출력합니다.

- `/resume`은 기록을 번호 목록으로 보여 줍니다. 번호를 입력하면 열립니다. 잘못된 번호를 치면 취소됩니다.

```sh
HARNESS_PLAIN=1 chaude
```
