## Detection / enforcement (how it works)

- official statement on mechanism: NOT FOUND. Only official language: legal page "Anthropic reserves the right to take measures to enforce these restrictions and may do so without prior notice." (row 1c).
- Thariq (row 6, secondary): "spoofing the Claude Code harness" safeguards; cites missing telemetry as the reason support is hard.
- Billing side (rows 8/9, secondary): April 2026 change is described as extra-usage billing for third-party harnesses, not as detection.
- User-report error text (NOT official, NOT re-verified): "This credential is only authorized for use with Claude Code and cannot be used for other API requests" appears in user bug reports on claudeissues.com (exact URL not recorded). Not found in Anthropic docs.

## Conflicts / caveats

- wording drift: The Register (Feb 20, 2026, secondary) quotes an older legal-page sentence: "Using OAuth tokens obtained through Claude Free, Pro, or Max accounts in any other product, tool, or service — including the Agent SDK — is not permitted and constitutes a violation of the Consumer Terms of Service." This sentence is NOT in the current legal page (re-verified 2026-10-31). Treat the current page as operative.
- tension: row 4 says CLAUDE_CODE_OAUTH_TOKEN is for "CI pipelines, scripts"; row 1 says OAuth is for "ordinary use of Claude Code and other native Anthropic applications"; row 1a bars Free/Pro/Max credentials in products "including those using the Agent SDK". Row 1b keeps the end user's own sign-in to the unmodified binary. No official sentence explicitly resolves whether a user's own script using the Agent SDK with their own subscription is allowed.
- GitHub issue #11: closed Mar 31, 2026 by "qing-ant" saying "Anthropic confirmed that Max + Agent SDK usage is permitted." No primary link; disputed in thread. UNVERIFIED.
- Dates conflict across secondary sources: enforcement Jan 9, 2026 (VentureBeat date); docs clean-up Feb 19, 2026; billing change Apr 4, 2026.
- Consumer Terms: English text not obtained. Do not cite Korean text as English verbatim.
