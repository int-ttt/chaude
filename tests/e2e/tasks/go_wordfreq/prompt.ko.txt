Go로 단어 빈도 세는 CLI 만들어줘. 프로젝트 폴더에 `go.mod`를 만들어서 모듈 초기화하고, 메인 파일은 `main.go` 하나로. 외부 패키지 없이 표준 라이브러리만 써.

- 실행 형태: `go run . [-n N] 파일1 [파일2 ...]`. `-n`은 상위 몇 개를 보여줄지고 기본값은 10이야.
- 파일 여러 개를 고루틴으로 동시에 읽어서 세고, 결과를 합쳐줘.
- 단어는 ASCII 영문자가 연속된 덩어리만 인정해. 숫자, 아포스트로피, 그 밖의 글자는 전부 구분자야 (예: `don't` → `don`, `t`). 대소문자는 무시하고 소문자로 통일.
- 출력은 한 줄에 `단어 횟수` 형식. 횟수 많은 순, 횟수 같으면 단어 사전순.
- 없는 파일이 하나라도 있으면 stderr에 에러를 찍고 종료코드 1로 끝내.
- 인자를 아무것도 안 주면 사용법을 찍고 종료코드 2로 끝내.

다 만들면 실행 방법이랑 구조를 한국어로 짧게 알려줘.
