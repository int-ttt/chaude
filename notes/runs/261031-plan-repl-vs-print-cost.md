# 계획: REPL vs claude -p 비용 비교 (261031)

created: 2026-10-31
status: 계획only (실행 전)
scope: 분석만. 구현 변경 금지. 이 파일 외 수정 금지.

## 1. 목적
- 목적: 두 세션을 병렬로 실행해 비용 비교.
- A: REPL(interactive) 모드
- B: claude -p 모드
- 공통: Opus 모델, 컨텍스트 한도 100k
- 구현 변경: 금지. 분석만 수행.

## 2. 실행 계획 (haiku-runner 수행)
- 작업 프롬프트: 동일 작업 프롬프트 1개를 A/B에 각각 투입.
- 실행: A/B 병렬 실행.
- 종료 후 수집: 토큰 사용량(입력 / 출력 / 캐시 읽기 / 캐시 쓰기), 소요 시간.
- 로그 저장(에이전트 간 전달용):
  - notes/runs/261031-cost-run-A.md
  - notes/runs/261031-cost-run-B.md
- 중단 규칙: 실행 전 haiku-runner가 실행 명령과 예상 토큰 범위를 보고하고, 승인 전까지 중단 가능 상태로 대기.

## 3. 비교 항목 (총 8개)
1. 입력 토큰
2. 출력 토큰
3. 캐시 읽기
4. 캐시 쓰기
5. 세션 간 컨텍스트 재사용 여부
6. 병렬 실행 시 중복 과금 여부
7. 100k 한도 도달 여부
8. 실패/재시도 횟수

## 4. 판정 규칙
- 측정값이 없는 항목: "미확인"으로 표기.
- 추정값: "추정"으로 명시하고 측정값과 구분.
- 측정 단위 명시: 토큰 수 기준. 달러 환산 여부를 항목마다 표기(환산 시 단가 출처와 날짜 명시).

## 5. 안전
- 실행은 과금이 발생함.
- 실행 전 보고 항목: 실행 명령, 예상 토큰 범위(입력/출력/캐시 구분), 예상 과금 범위.
- 보고 후 사용자 승인 전까지 실행 금지. 중단 가능하게 유지.
