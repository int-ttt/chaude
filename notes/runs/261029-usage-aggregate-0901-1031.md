## what the numbers count
- records: every JSON line with a parseable timestamp inside the window (any type).
- sessions: distinct non-empty sessionId over kept records.
- raw_sum: input/output/cache_read/cache_creation tokens summed over every assistant record carrying message.usage.
- dedup_sum: same, but one entry per message.id (first record kept); distinct_msg_ids counts those.
- tool_use counts: distinct tool_use block ids per tool name (name from the block).
- split pre = 09-01..10-26 UTC, post = 10-27..10-31 UTC, by record timestamp date.
