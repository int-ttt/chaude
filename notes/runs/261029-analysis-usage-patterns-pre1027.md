## 4. 해석 (모두 추정)
1. 사용이 소수의 대형 장기 세션(특히 VocalAnalyze 한 프로젝트)에 집중되어 있고, 작업 방식은 Bash 중심의 실행/검증 반복으로 보입니다.
2. 비용 구조는 출력보다 컨텍스트 재읽기(cache_read)가 지배적입니다. 캐시 적중률이 높아 단가는 낮겠지만 양이 커서, 긴 세션을 유지하는 만큼 총량이 커집니다. 단가를 적용하지 않아 실제 비용은 알 수 없습니다.
3. opus-5와 sonnet-5가 호출량의 대부분을 나눠 갖고, 저가 모델 구분(haiku 등)은 이 기간 요약에 나타나지 않습니다.
4. 야간(한국시간) 집중과 며칠씩 비는 날이 섞여, 몰아서 작업하는 패턴으로 보입니다.

## 5. 불확실한 점
- 세션이 7개뿐이고 11,419줄은 타임스탬프가 없어 제외되었습니다. 세션 ID가 없거나 서브에이전트 파일에서 세션 구분이 흐려졌을 가능성이 있어 세션별 수치(중앙값 등, 토큰은 n=3)는 신뢰도가 낮습니다.
- 모델 분포는 message.model이 있는 레코드만 셉니다. 한 응답이 여러 레코드로 쪼개져 usage가 중복 합산되었을 가능성이 있어 토큰 합계는 과대일 수 있습니다 (확인 안 함).
- 시간대는 UTC 집계이며 한국시간 환산은 가정입니다.
- 하네스 메트릭 0건이므로 라우팅/티어 분석은 이 기간에 대해 불가합니다.
- settings는 현재값이라 당시 설정과 다를 수 있습니다.
