## 1. 질문 원문

## 2. 두 구성 정의와 훅상 실제 허용 경로

- 구성 A (opus-haiku): opus가 haiku-* 에이전트만 호출한다.
- 구성 B (opus-sonnet-haiku): opus가 sonnet-analyst·sonnet-reviewer를 거치고, 그 아래에서 haiku-*를 쓴다.

훅 규칙 (.claude/hooks/agent-model-pin.py 기준):

| 호출 경로 | 판정 | 근거 행 |
|---|---|---|
| 메인 → opus-architect | 허용 | :45 (메인은 :45 조건 밖), :86-91 model 인자 제거 |
| 메인 → sonnet-analyst / sonnet-reviewer | 허용 | :86-91 (메인 스레드 제한 없음) |
| opus-architect(서브) → haiku-* | 허용 (구성 A의 실제 경로) | :45-50 통과, :75-79 통과 |
| opus-architect(서브) → sonnet-analyst / sonnet-reviewer | 거부 (구성 B의 정의대로 한 경로) | :45-50 ("sonnet/opus 서브에이전트는 haiku-*만"), :75-79 backstop |
| sonnet-analyst / sonnet-reviewer(서브) → haiku-* | 허용 | :45-50 통과 |
| haiku-prompter(메인 전용) → sonnet-* / opus-* / haiku-* | 허용 | :39-41 조기 허용 |

결론: 구성 B를 "opus가 sonnet을 호출"로 정의하면 현재 훅에서 거부됩니다. 구성 B가 실제로 가능한 경로는 메인 → sonnet-* → haiku-*, 또는 haiku-prompter → sonnet-* 입니다. 따라서 "B의 토큰"은 현재 정책에서 opus가 sonnet을 부른 결과로 존재하지 않습니다. 이 점은 plan-opus-drives-sonnet-review.md 의 안 A(:45-50 예외 추가 검토)와 같은 쟁점입니다.

## 3. 비교 지표

지표는 에이전트 타입별로 다음 항목을 계산합니다.

- 호출 수: 서브에이전트 transcript 수
- 호출당 평균: 토큰 합계 / 호출 수

- out.txt 에는 transcript 단위 dedup 합계(ded_usage_sum)와 raw 합계(raw_usage_sum)가 있습니다. 주 지표는 dedup, 보조는 raw로 둡니다.

## 4. 판정 기준

- 기준값: 두 구성의 대응 값 차이가 ±10% 이내이면 "비슷하다", 그 밖이면 "비슷하지 않다".
- 대응 값: (a) 호출당 평균 합계, (b) 합계 비율. 둘 다 같은 방향이어야 "비슷하다"로 판정합니다. 둘 중 하나라도 ±10% 밖이면 "비슷하지 않다"입니다.
- 한계: 위 기준을 구성 단위로 적용하려면 구성별 합계가 필요합니다. out.txt는 에이전트 타입 단위라 구성 단위 합계를 만들 수 없습니다. 아래 판정은 sonnet 측 대 haiku 측 프록시 비교입니다.

### 4-1. 프록시 판정 (수치 근거)

- (a) 호출당 평균: haiku-* 92,123 대 sonnet-* 166,028. 차이 +80.2%. 기준 밖.
- 참고: 단일 에이전트 비교 haiku-scout 70,232 대 sonnet-analyst 172,319. 차이 +145%. 기준 밖.
- (b) 합계 비율: sonnet-* / haiku-* = 47,650,120 / 82,450,673 = 57.8%. 기준 밖(100%에서 10% 이내가 아님).
- 항목별 비율(dedup): 입력 51.3%, 출력 28.7%, 캐시 생성 45.0%, 캐시 읽기 63.6%.
- 호출 수 비율: sonnet 287 대 haiku 895 (32.1%). 호출 수 차이만으로도 합계 차이가 설명되지 않습니다. 호출당 평균도 크게 다릅니다.

### 4-2. 판정 (잠정)

- 프록시 판정: 비슷하지 않음. 근거는 3-1 표의 호출당 평균(+80.2%)과 합계 비율(57.8%)입니다.
- 구성 A 대 구성 B 판정: 미확인. 근거: out.txt에 구성 구분 필드가 없습니다. meta의 parentAgentId는 730건에만 있고, 본 문서에서 추출하지 않았습니다. 구성 B의 opus→sonnet 경로는 훅에서 거부되므로 실측 구성 B 자체가 제한됩니다(2절).
