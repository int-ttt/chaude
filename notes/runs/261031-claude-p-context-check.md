# claude -p 맥락 유지 검증 (2026-10-31)

## 판정
주장 "호출 간 컨텍스트가 저장되지 않는다"는 부분적으로만 참입니다. 플래그 없는 기본 -p 호출은 서로 기억을 공유하지 않지만(참), --resume <session-id>로는 맥락이 유지됩니다(실험 확인). 즉 "항상 저장되지 않는다"는 거짓입니다.

## 실험 (haiku, cwd /tmp/cpctx, 총 6개 묶음, 모두 exit 0)
- E1: 기본 -p "내 이름은 철수야" -> OK, session_id 22e5937c-5902-4bf5-aa1b-0bb3f1e8f01d (세션 파일은 기본으로 저장됨)
- E2: 새 기본 -p "내 이름이 뭐야?" -> "모름" (기억 공유 없음: 확인)
- E3: --resume <E1 id> -> "철수" (맥락 유지: 확인)
- E4: --continue -> "철수" (단, E3 직후 실행이라 가장 최근 세션이 E1 세션이었음. --continue가 최근 세션을 잇는다는 정황이며, 단독 검증은 아님)
- E5: --session-id <새 uuid> "내 암호는 파랑" 후 --resume 같은 uuid "내 암호가 뭐야?" -> 기억 못 함. 다만 "암호"라는 민감 단어에 대한 모델의 거부 응답일 가능성이 있어 원인 미확인입니다. --session-id 유지 여부는 미확인(재실험 필요, 비민감 단어로).
- E6: --no-session-persistence "내 이름은 영희" 후 --continue -> 영희 기억 못 함. --continue가 다른(E1/E3) 세션을 집어 격리되지 않은 실험이라 "no-persistence면 저장 안 됨"은 정황만 있고 미확인입니다.

## 유지 조건 정리
- 기본 -p 반복 호출: 유지 안 됨 (확인)
- --resume <session-id>: 유지됨 (확인)
- --continue: 같은 cwd의 가장 최근 세션을 이어감 (정황, 격리 재검증 미확인)
- --session-id <uuid>: 미확인
- --no-session-persistence: 저장 안 될 것으로 추정, 미확인
