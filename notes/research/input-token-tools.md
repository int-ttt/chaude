| 1 | context-mode (mksglu/context-mode) | MCP server plus hooks; "Context window optimization for AI coding agents" | Tool output runs in a sandbox (ctx_execute, ctx_execute_file); only stdout enters context. ctx_index chunks into SQLite FTS5, ctx_search returns BM25 snippets. ## Relevance notes (facts from sources, no recommendation)
- RTK and Token Savior Bash rewriting act only on Bash tool output; RTK hook does not cover Read/Grep/Glob.
- Serena file/shell tools are disabled by default in Claude Code.
- caveman per-request overhead (~1,160 input tokens) can make short sessions net-negative per the page's own warning.
